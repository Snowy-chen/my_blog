## 常用的工具类

#### Partial<T>、Required<T>

*都是浅层的，如果需要深度递归遍历，必须自定义 `DeepPartial` / `DeepRequired`。*

Partial<T> 给类型全部添加?  ,  表示可选。 Required<T> 去掉类型里的全部 ? 

```jsx
interface User {
  id: number;
  name: string;
  email: string;
  avatar: string;
  bio: string;
}

// 更新时只传要改的字段， 配合 Omit 将 id 去掉。其他变成可选
type UpdateUserDTO = Partial<Omit<User, "id">>;
```

#### Pick<T, K>  、 Omit<T, K>

Pick<T, K> 在大类型中挑选想要字段（只想要这几个字段）

```jsx
interface User {
  id: number;
  name: string;
  email: string;
  avatar: string;
  bio: string;
  createdAt: string;
  updatedAt: string;
}

// 列表接口只返回这些字段
type UserListItem = Pick<User, "id" | "name" | "avatar">;
```

 Omit<T, K> 在大类型中挑选不要的字段（除了这几个字段，其他都要），用来排除主键、时间戳，敏感字段。

```jsx
interface User {
  id: number;
  name: string;
  email: string;
  password: string;
  createdAt: string;
  updatedAt: string;
}

// 创建时 id、时间戳由服务端生成，不需要传
type CreateUserDTO = Omit<User, "id" | "createdAt" | "updatedAt">;

async function createUser(data: CreateUserDTO) {
  return request<User>("/api/users", { method: "POST", body: data });
}
```

#### **`Record<K, T>`：描述映射关系**

**"键到值的查表"**。凡是"根据某个 key 查一个值"的场景，都优先考虑 `Record`

```jsx
type OrderStatus = "pending" | "paid" | "cancelled" | "done" | "confirmed" 

const statusText: Record<OrderStatus, string> = {
	"pending": "待支付",
	"paid": "已支付",
	"cancelled": "已取消",
	"done": "已完成",
	"confirmed": "已确认",
}
```

#### **`Exclude<T, U>`：从联合中排除，`Extract<T, U>`：从联合中提取**

**`Exclude<T, U>` 这个联合里不要这几个，**注意它只对**联合类型**有意义，对对象类型没有作用。

```jsx
type AppEvent = "click" | "hover" | "scroll" | "resize" | "error";
type UserEvent = Exclude<AppEvent, "resize" | "error">;
```

**`Extract<T, U>` 这个联合中只要这几个**

```jsx
type AppEvent = "click" | "hover" | "scroll" | "resize" | "error";
type UserEvent = Extract<AppEvent, "click" | "hover" | "scroll"; //等价上方的逻辑

type AppEvent =
  | { type: "click"; x: number; y: number }
  | { type: "keydown"; key: string }
  | { type: "scroll"; top: number }
  | { type: "error"; message: string };
  
  
type MouseEvent = Extract<AppEvent, {type: "click"}> // 就可以将 click 类型的集合找出来

```
